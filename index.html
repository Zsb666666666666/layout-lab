这是一个围绕网页布局原理制作的交互式教学案例。

理论重点

视觉层级、空间关系、Flex、Grid、媒体查询与响应式设计。

技术实现

原生 HTML、CSS、JavaScript，可直接部署到 GitHub Pages。

学习原则

案例为中心；每个概念都配有可运行的视觉结果。
